# 8. 下載格式

支援回傳檔名或直接二進位串流。

---

## 回傳格式

### Base64
**適合小型檔案下載**

**優點：**
- 可以回傳其他資訊（如成功訊息）

**缺點：**
- 檔案變大 33%
- 記憶體負擔大

**回傳範例格式：**
```json
{
  "statusCode": "200",
  "messageCode": null,
  "message": "執行成功",
  "data": {
    "exportFileData": "77u/LCwsLCzlpKfkuovntIDs...",
    "exportFileName": "大書紀資料明細資料表.csv"
  }
}
```

---

### application/octet-stream
**適合大型檔案下載（需要額外處理 response header Content-Disposition 來取得檔名）**

**優點：**
- 效能最佳
- 支援大檔案
- 下載體驗好

**缺點：**
- 無法回傳其他訊息

---

## ODS（ODF）匯出

報表需要 ODS 時，後端一律呼叫共用元件 `ReportResponseEntityUtils.writeOds(fileName, workbook)`，不要各自去接 LibreOffice。

### 產生方式（兩段式）

| 順序 | 方式 | 說明 |
| --- | --- | --- |
| 1 | LibreOffice 轉檔 | 先把 POI Workbook 寫成 xls/xlsx 暫存檔，再交由 LibreOffice 轉 ODS。版面與原 Excel 一致。 |
| 2 | 純 Java 產生（fallback） | LibreOffice 未安裝、轉檔失敗或結果為空時自動改走這條路（`OdsUtils`），API 不會因此失敗。 |

目前伺服器的 LibreOffice 仍有問題，所以實務上大多會落到第 2 條路。

### 純 Java 產生的差異（測試重點）

| 項目 | 是否保留 |
| --- | --- |
| 多工作表、工作表名稱 | 保留 |
| 儲存格顯示文字（含公式計算後的結果、日期／數值顯示格式） | 保留 |
| 字型、顏色、框線等樣式 | 不保留 |
| 合併儲存格 | 不保留，合併會被拆成各自獨立的儲存格 |
| 第 1 列 | 一律當成標題列輸出 |
| 欄寬 | 不保留，由試算表軟體自動調整 |
| 圖片、圖表 | 不保留 |

> 測 ODS 下載時，順便比對「舊系統既有報表」與「新產出的 ODS」版面是否相同，有落差回報後端。

### 需要保留合併儲存格的報表

由該報表自行組出 ODS bytes 再回傳，不要走 `writeOds`：

```java
byte[] odsBytes = OdsUtils.buildOdsBytesWithMerge(
        List.of(new OdsUtils.OdsSheetWithMerge(sheetName, headers, rows)));
return ReportResponseEntityUtils.writeOdsBytes(fileName + ".ods", odsBytes);
```

現行採用此做法的報表：PTM070B03、RFM032B24、薪資查詢報表、學生放棄確認表。

### 前端取檔

- Content-Type：`application/vnd.oasis.opendocument.spreadsheet`
- 以 octet-stream 串流回傳，檔名放在 `Content-Disposition`（經 URLEncoder 編碼，前端需 decode）
